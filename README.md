# Telegram-bot-for-minecraft

Telegram бот для Minecraft сервера с функцией RCON-управления.

## ✨ Возможности

- 📊 Показ онлайн-статистики сервера
- 📜 Отображение правил сервера
- 💰 Ссылки на донат-систему
- 🔗 Быстрый доступ к чатам сервера
- ⚙️ RCON-панель для администраторов
- 🎮 Управление Minecraft сервером через Telegram

## 🛠 Технологии

- Python 3.x
- `pyTelegramBotAPI` - для работы с Telegram Bot API
- `mcrcon` - для подключения к RCON серверу Minecraft
- Регулярные выражения - для парсинга ответов RCON
